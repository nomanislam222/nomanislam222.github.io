## What's here

| Path | Purpose |
|---|---|
| `index.html` | The whole site — semantic HTML with JSON-LD `Person` structured data |
| `assets/styles.css` | Design system, layout, dark/light themes, responsive rules |
| `assets/main.js` | Theme toggle, scroll-spy, reveal animations, research filter, counters |
| `assets/MD-Noman-Islam-CV.pdf` | Downloadable CV |

## Features

- Dark and light themes, remembered per visitor and defaulting to the OS setting
- Fully responsive from 320px upward
- Animated hero, scroll-reveal sections, animated statistics, filterable research cards
- Accessible: skip link, focus-visible outlines, ARIA states, `prefers-reduced-motion` respected
- SEO ready: canonical URL, Open Graph tags, `sitemap.xml`, `robots.txt`, JSON-LD
- Zero build step and zero JavaScript dependencies — static files only

## Running locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
